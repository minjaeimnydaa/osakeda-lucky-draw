기본 설정

참여 규칙: 고객당 하루 1회 · 기간 중 1회 당첨
한국 시간 오전 0시 초기화

경품과 추첨 확률

확률은 각 경품의 당첨 확률입니다. 합계는 100% 이하로 설정하세요. 소진된 경품의 확률은 꽝으로 처리합니다.

1차 버전은 기간 전체 재고를 사용합니다. 날짜별 배분과 전량 당첨 보장은 포함하지 않습니다. 참여 기록이 생긴 뒤 기간·경품명·금액·확률을 바꾸려면 새 이벤트로 복제하세요.

고객 안내

고객 식별값은 코드 발급 시 암호학적 해시로 저장되며, 당첨 이메일은 발급에 필요한 정보로 저장됩니다. 운영자가 안내한 보관 기간에 맞춰 데이터베이스에서 삭제해야 합니다.

구매 고객 참여 코드 발급

고객별로 변하지 않는 식별값을 한 줄에 하나씩 입력하세요. 같은 고객의 여러 주문은 반드시 같은 고객 ID 또는 이메일을 사용하세요. 주문 번호만 사용하면 고객별 제한을 지킬 수 없습니다.

원본 코드는 발급 직후 한 번만 제공됩니다. 내려받은 CSV를 안전하게 보관하고 고객별로 전달해 주세요. 재발급한 코드도 같은 고객의 참여 제한을 공유합니다.

발급이 완료되었어요. 다운로드가 시작되지 않았다면 아래 버튼으로 다시 저장하세요. 이 화면을 떠나면 원본 코드를 다시 볼 수 없습니다.
