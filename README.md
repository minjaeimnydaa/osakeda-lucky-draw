# OSAKEDA Lucky Draw

오사케다 구매 고객을 위한 럭키 드로우 이벤트입니다. 최신 방향은 Shopify 스토어 안에 이벤트 전용 페이지를 두는 것입니다. 예시 주소는 `/pages/lucky-draw`이며, 실제 페이지 생성·설치·Shopify 연동은 아직 구현하지 않았습니다.

현재의 깔끔한 화면, 집게 모션, **참여 코드 입력 → 추첨 → 당첨 시 수령 이메일 등록** 흐름을 유지합니다. 추첨·재고·고객당 하루 1회 참여·기간 중 최대 1회 당첨·참여 기록은 별도 서버와 DB가 처리합니다. 구매 고객 로그인 및 구매 이력 자동 확인은 이후 범위이며, 로그인만으로 구매 고객이 확인되는 것은 아닙니다.

| 프로젝트 | 용도 | 로컬 주소 |
|---|---|---|
| `lucky-draw` | 현재 버전 | http://localhost:3000 |
| `lucky-draw-v2` | 별도 개선 버전 | http://localhost:3001 |

Node.js 24 이상에서 각 프로젝트 폴더의 `node server.js`를 실행합니다. 테스트는 각 폴더에서 `node --test test/*.test.js`로 실행합니다.

기존 참여·당첨 기록과 관리자 설정도 함께 옮길 때는 **서버를 처음 실행하기 전에** [TRANSFER.md](TRANSFER.md)를 확인합니다. 두 버전의 기록을 암호화해 백업하고 새 컴퓨터에서 복원하는 도구가 `tools/records.mjs`에 있습니다.

기존 baseline과 V2는 독립된 기준 버전으로 보존합니다. 화면·기능 수정, 관리자 설정 변경, 다른 컴퓨터에서 작업하기와 Shopify 적용 절차는 [UPDATES.md](UPDATES.md)에 정리했습니다. 코드는 작업 브랜치에서 확인한 뒤 `main`에 반영하고, Shopify 화면은 **테마 복사본 → 미리보기 → 검증 → 공개** 순서로 적용합니다.

최종 서버 호스팅은 아직 선택하지 않았습니다. Netlify + Neon은 무료 범위의 후보이며, Vercel은 과거 검토 후 미배포 상태입니다. 기존 Vercel 설정과 각 프로젝트 README의 배포 예시는 검토 기록으로 남깁니다.

로컬 실행은 각 프로젝트 README, V2 개선 사항은 [V2-NOTES.md](lucky-draw-v2/V2-NOTES.md)를 참고합니다. 로컬 테스트 DB와 비밀번호는 실행 시 각 프로젝트에 따로 생성되며 Git에는 포함되지 않습니다. 참여·당첨·이메일 기록과 CSV 내보내기, 화면 캡처, 설치된 의존성도 제외합니다.
